Description: The Official ESPHome Starter Kit is a way to build your own smart home devices with no soldering, breadboards or coding experience. You plug in a module, set it up in the visual ESPHome Device Builder, and use it standalone or with Home Assistant. Everything runs locally with no cloud, subscriptions or accounts. The majority of profit supports the Open Home Foundation.

Features:
- Solder-free: modules snap off the panel and connect to the main board with a single FPC ribbon cable
- Any two modules can run at the same time to make a multisensor
- Example projects on site: PIR motion light, temperature and humidity automations, button-triggered Home Assistant automations, status colors and chimes from the Casita module
- Learning Wiki explains each step
- Modules: PIR motion, temperature and humidity, ESPHome Casita notification module (10 RGB LEDs and a piezo buzzer), button module
- Main board has an onboard RGB LED, 2 x 14-pin FPC ports, USB-C power with optional LiPo battery support
