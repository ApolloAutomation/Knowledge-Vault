Description: The Apollo DEV-2 is a development board for prototyping and custom projects. It uses an ESP32-C6-MINI-1 chip with USB-C for power and data, GPIO, I2C and an RGB LED. Compared with the DEV-1 it also supports Thread and Zigbee. It ships with pre-soldered headers.

Features:
- ESP32-C6-MINI-1 chip: WiFi, Thread, Zigbee and Bluetooth enabled
- USB-C for power and data
- GPIO and I2C interfaces for easy sensor integration
- Built-in RGB LED indicator on GPIO 3
- Pre-soldered headers
- Use cases listed on site: Home Assistant, IoT, automation solutions, prototyping and custom projects
