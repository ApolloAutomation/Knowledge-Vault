Description: A non-contact capacitive fluid sensor that attaches to the [[PUMP-1]] to sense whether a fluid container is wet or dry.

Features:
- Non-contact capacitive fluid sensor
- The sensor should not be submerged in liquids
- Cable can be extended using the cables sold on the site
- PUMP-1 has two ports for fluid sensors, so the pump can stop when watering is done or the bottle runs empty
- Wiki guide linked from the product page (Pump-1 Fluid Sensor WIKI)

Compatible with: [[PUMP-1]]

Included/variants: Single item. Also sold inside the [[PUMP-1-Full-Accessory-Kit]] (two sensors) and as a PUMP-1 add-on.
