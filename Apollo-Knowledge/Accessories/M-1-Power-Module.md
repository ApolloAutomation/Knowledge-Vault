Description: A power module that adds extra power when connecting multiple HUB75 LED matrix panels. It is powered via USB-C. On the controller page the site also says it lets you easily power a HUB75 panel with USB-C, and to use it with the data cable so the M-1 controller works with other HUB75 panels.

Features:
- Adds power for multi-panel HUB75 setups
- Powered via USB-C

Compatible with: [[M-1]], [[HUB75-Matrix-Panel]], [[M-1-Controller]]

Included/variants: Optional add-ons: USB-C cable (1.5m / 5ft), top facing USB-C wall plug (USA plug). Also included in the multi-panel kits described in [[M-1]].
