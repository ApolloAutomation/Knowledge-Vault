Description: The mount-only version of the R PRO-1 gang box mount. It is made from UL94-V0 flame-retardant plastic and mounts a sensor inside a standard gang box with a fully recessed design that hides the sensor. The gang box is NOT included.

Features:
- UL94-V0 flame-retardant plastic
- Fully recessed to hide the sensor for a clean installation
- Fits standard electrical gang boxes; secure mounting inside the box
- Suitable for residential, commercial and industrial environments
- Meets flame-retardant requirements; clean, low-profile finish
- Variant: 3D Printed Mount Only
- The full kit adds a single gang box and blank wall plate: [[R-PRO-1-Gang-Box-Mount-Kit]]

Compatible with: [[R-PRO-1]]

Included/variants: 3D printed mount only. Gang box not included ([[R-PRO-1-Gang-Box-Only]], [[R-PRO-1-Gang-Box-Cover-Only]] sold separately).
