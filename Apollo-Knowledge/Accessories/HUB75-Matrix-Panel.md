Description: The HUB75 matrix panel on its own, without the M-1 controller. A controller is necessary to use the panel. The site notes P2.5 (2.5mm) pitch, which is the spacing between LEDs, and credits the WLED-MM team.

Pixel count: Not stated on site (the M-1 page lists 4096 pixels)
LED pitch: P2.5 (2.5 mm, spacing between LEDs)

Features:
- HUB75 LED matrix panel only
- P2.5 / 2.5mm LED pitch
- Controller not included

Compatible with: [[M-1]] (use with [[M-1-Controller]]); extra panels for multi-panel setups also need [[M-1-Data-Cable]] and [[M-1-Power-Module]]

Included/variants: Single panel only. Panel-plus-stand kits are folded into [[M-1]].
