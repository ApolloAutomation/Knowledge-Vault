# HUB75-Matrix-Panel

## Description

The HUB75 matrix panel on its own, without the [[M-1]] controller. A controller is necessary to use the panel. It has a P2.5 (2.5 mm) pitch, which is the spacing between LEDs. Apollo credits the WLED-MM team.

## Features

- HUB75 LED matrix panel only
- P2.5 / 2.5 mm LED pitch
- Controller not included

## Specs

- Pixel count: Unknown — escalate to support. The [[M-1]], which uses this panel, lists 4096 pixels
- LED pitch: P2.5 (2.5 mm, spacing between LEDs)

## Compatible with

- [[M-1]] (use with the M-1-Controller)
- Extra panels for multi-panel setups also need an M-1-Data-Cable and an M-1-Power-Module

## What's in the box

A single panel only. Panel-plus-stand kits are listed under [[M-1]].

## Common questions and answers

### Does the HUB75 panel come with a controller?

No. This is the panel only, and a controller is necessary to use it. Use it with the M-1-Controller, or buy the complete [[M-1]].

### How do I add another panel to my M-1?

Each extra panel needs the panel, an M-1-Data-Cable and an M-1-Power-Module. The [[M-1]] supports up to four panels connected horizontally; extra power injection is needed for the full effect. Multi-panel kits are listed under [[M-1]].

### What is the LED pitch of the HUB75 panel?

P2.5, meaning 2.5 mm spacing between LEDs.
