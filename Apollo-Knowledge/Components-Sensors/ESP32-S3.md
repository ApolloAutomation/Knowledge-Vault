# ESP32-S3

## Description

The Espressif ESP32-S3 is the microcontroller on the [[CAST-1]] and [[CAST-PRO-1]] (CAST PRO-1) audio casting devices, and it is listed in the [[M-1]] LED matrix product details. The CAST-1 version has 16 MB flash and 8 MB PSRAM. The M-1 controller ships pre-flashed with WLED.

## Used in

- [[CAST-1]]
- [[CAST-PRO-1]]
- [[M-1]]
- M-1-Controller (the M-1's controller board)

## Specs

- Operating range: Unknown — escalate to support
- Wifi capability: 2.4 GHz Wi-Fi (CAST-1 and CAST PRO-1)
- Can be bluetooth proxy: Yes. The CAST-1 is Home Assistant Bluetooth Proxy capable; the CAST PRO-1 uses Bluetooth LE for Bluetooth proxy and Improv Wi-Fi setup
