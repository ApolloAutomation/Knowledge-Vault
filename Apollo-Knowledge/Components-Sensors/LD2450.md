# LD2450

## Description

The HLK-LD2450 is a 24 GHz mmWave radar module. It provides multi-target, multi-zone motion tracking, reporting where people are using x/y coordinate zones that you set up. It is the main presence radar on the [[MTR-1]] and the built-in radar on the [[R-PRO-1]] (R PRO-1). On the R PRO-1 it can be paired with the optional [[LD2412]] for still presence.

The LD2450 has no sensitivity setting, and ESPHome does not offer one either, so it cannot be tuned gate by gate like the LD2410B on the MSR-2.

## Used in

## Specs

- Number of occupants: Up to 3 targets tracked at the same time
- Distance: Up to about 6 m (19.7 ft) detection range
- Max distance: About 6 m (19.7 ft)
- Max targets: 3
- Number of zones: 3 (up to 3 people in up to 3 zones)
- Field of view: Unknown — escalate to support
- Max square footage of coverage given height off ground: Unknown — escalate to support
- Mounting orientation: Unknown — escalate to support
