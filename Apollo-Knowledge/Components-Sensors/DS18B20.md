# DS18B20

## Description

The DS18B20 is a digital 1-Wire temperature probe. Apollo sells optional waterproof flat-cable DS18B20 probes in two lengths, the [[Short-Temperature-Probe]] and the [[Long-Temperature-Probe]]. They work with [[TEMP-1]] and with [[PLT-1]] (as a soil temperature probe). The [[Apollo-Breakout-Module]] has a 1-Wire port for DS18B20 probes; in ESPHome, use the One Wire component on GPIO6 with the Dallas temperature sensor. Use cases include fridges, freezers and fish tanks.

The [[TEMP-1-Food-Probe]] is a stainless steel NTC probe, not a DS18B20.

## Used in

- [[PLT-1]] - optional waterproof soil temperature probe
- [[TEMP-1]] - optional waterproof flat-cable temperature probes (3.5mm jack)
- [[Apollo-Breakout-Module]] - 1-Wire port (data on GPIO6)
- [[ESK-1]] - short and long temperature probes are optional add-ons (require the Breakout Module)

## Specs

- Interface: 1-Wire
- Apollo probe type: DS18B20 waterproof flat cable (submersible)
- Apollo probe lengths: short 20 cm ([[Short-Temperature-Probe]]), long 1.5 m ([[Long-Temperature-Probe]])
- Apollo probe max temperature: 85 °C / 185 °F
- ESPHome setup on the Breakout Module: One Wire component on GPIO6 with the Dallas temperature sensor

## Datasheet figures (chip manufacturer, not an Apollo rating)

Source: Maxim DS18B20 datasheet (REV 042208)

- Measurement range: -55 to +125 °C (Apollo's probes are rated to 85 °C max)
- Accuracy: ±0.5 °C from -10 to +85 °C
- Resolution: 9 to 12 bits, selectable
- Interface: 1-Wire, with a unique 64-bit serial code
