Description: The PCM5122 is a Texas Instruments stereo DAC (digital-to-analog converter) used for the analog audio output on the CAST-1 and CAST PRO-1. On the CAST-1 it drives the 3.5mm analog stereo line out to powered speakers, amplifiers and AV receivers.
Used in: [[CAST-1]], [[CAST-PRO-1]]
DAC type: Texas Instruments 32-bit stereo (per the CAST-1 page)
SNR / dynamic range: 112 dB (per the CAST-1 page)
THD+N: -93 dB (per the CAST-1 page)
Output level: 2.1 VRMS full scale, 3.5mm analog stereo line out (per the CAST-1 page)
Sample rate: Playback 48 kHz / 16-bit stereo in the open source firmware; DAC capable of up to 384 kHz (per the CAST-1 page)
Figures on CAST PRO-1 page: Not stated on site (page only says analog out uses a PCM5122 DAC)
ADC: Not stated on site (CAST PRO-1 page lists a 3.5mm Line In but names no ADC part)

Source: Texas Instruments PCM5121/PCM5122 datasheet (SLAS763C); the SNR, THD+N and output figures above match the CAST-1 page.
Sample rate (datasheet): 8–384 kHz
