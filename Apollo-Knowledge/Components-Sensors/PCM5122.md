# PCM5122

## Description

The PCM5122 is a Texas Instruments stereo DAC (digital-to-analog converter). It drives the analog audio output on the [[CAST-1]] and the [[CAST-PRO-1]]. On the CAST-1 it drives the 3.5mm analog stereo line out to powered speakers, amplifiers and AV receivers. On the CAST PRO-1 the analog output uses the PCM5122.

## Used in

- [[CAST-1]] - DAC for the 3.5mm analog stereo line out
- [[CAST-PRO-1]] - DAC for the analog audio output

## Specs

- CAST-1 DAC type: Texas Instruments 32-bit stereo
- CAST-1 SNR / dynamic range: 112 dB
- CAST-1 THD+N: -93 dB
- CAST-1 output level: 2.1 VRMS full scale, 3.5mm analog stereo line out
- CAST-1 sample rate: Playback 48 kHz / 16-bit stereo in the open source firmware; the DAC is capable of up to 384 kHz
- CAST PRO-1 audio figures (SNR, THD+N, output level): Unknown — escalate to support
- CAST PRO-1 Line In ADC: Unknown — escalate to support (the CAST PRO-1 has a 3.5mm Line In, but the ADC part is not named)

## Datasheet figures (chip manufacturer, not an Apollo rating)

Source: Texas Instruments PCM5121, PCM5122 data sheet, SLAS763C, August 2012, revised October 2018 (https://www.ti.com/lit/ds/symlink/pcm5122.pdf)

- SNR and dynamic range: 112 dB
- THD+N at -1 dBFS: -93 dB
- Full-scale output: 2.1 VRMS, ground-centered
- Sample rate: 8–384 kHz
- Audio data: 16, 20, 24 and 32 bit
