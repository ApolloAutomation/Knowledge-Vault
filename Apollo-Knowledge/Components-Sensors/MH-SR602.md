# MH-SR602

## Description

The MH-SR602 is a PIR (passive infrared) motion sensor module. It is the PIR motion module included in the [[ESK-1]] ESPHome Starter Kit.

- [[ESK-1]]

## Specs

- Detection range: 0 to 3.5 m
